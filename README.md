## Arduino Integration

The project includes an Arduino-based vehicle monitoring component
that collects distance measurements using an ultrasonic sensor.

### Hardware Components

* Arduino board
* HC-SR04 ultrasonic distance sensor
* Servo motor
* Buzzer
* Push button

### Features

* Distance measurement using the HC-SR04 sensor
* Serial communication for transmitting sensor readings
* Servo motor control
* Buzzer output for alert functionality
* Button input for user interaction

### Source Code

The Arduino source code is available in:

`arduino/vehicle_monitor.ino`
